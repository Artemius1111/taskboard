1. Яка адреса сторінки в браузері? З яких частин вона складається?
Адреса: http://127.0.0.1:5500/index.html. Протокол http, хост 127.0.0.1 (localhost, тобто мій власний комп'ютер), порт 5500 (на ньому працює Live Server), шлях /index.html (файл, який я запитую).

2. Скільки запитів зробив браузер при завантаженні сторінки і чому саме стільки?
Браузер зробив 3 запити. Спочатку він отримав index.html, побачив у ньому тег <img> і окремо запросив images/logo.png. Live Server додав у сторінку свій скрипт, який відкрив WebSocket (запит ws, статус 101 Switching Protocols) для автооновлення сторінки при збереженні файлу. Через цей скрипт index.html у Network важить 2.4 kB, хоча сам файл менший.

3. Що відбулось, коли ти поставив неправильний шлях до зображення?
Сервер не знайшов файл images/logo1.png і повернув статус 404 Not Found. У вкладці Network цей запит став червоним, а на сторінці замість картинки з'явився текст з атрибута alt. Сам index.html при цьому завантажився нормально зі статусом 200.

4. Чому зміни, зроблені через DevTools, зникли після F5?
Через DevTools я змінював DOM — копію сторінки в пам'яті свого браузера, а не файл index.html на сервері. Після F5 браузер знову запитав index.html у сервера і отримав оригінальний вміст, тому всі зміни зникли. Інші користувачі цих змін узагалі не бачили.

5. Хто в цій схемі клієнт, а хто сервер?
Клієнт — браузер, який надсилає HTTP-запити. Сервер — Live Server, що працює на моєму ж комп'ютері за адресою 127.0.0.1:5500 і віддає файли з папки taskboard.
  
## Лабораторна 4. Git у терміналі

**1. Що змінилося у виводі `git status` після `git add`?**
Файл `index.html` перейшов зі списку Untracked files (червоний) у список
Changes to be committed (зелений), тобто потрапив в індекс і піде в наступний commit.
Інші файли залишились Untracked.

**2. Що показує `git diff`?**
Різницю між робочою папкою та останнім commit-ом: рядки з `+` додані, рядки з `-` видалені.

**3. Чим відрізняється `git switch main` від `git merge`?**
`git switch main` лише перемикає на гілку main, і файли в папці змінюються на її версію.
`git merge` переносить зміни з іншої гілки в поточну.

**4. Чому виник конфлікт і як ти його розв'язав?**
У гілках main і ukr-title по-різному змінили той самий рядок із заголовком `<h1>`,
тому Git не зміг сам вибрати варіант. Я видалив службові рядки `<<<<<<<`, `=======`, `>>>>>>>`,
поєднав обидва варіанти в `<h1>Дошка завдань: керуй завданнями</h1>` і зробив commit.
